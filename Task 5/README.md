# Netflix Duration Analysis

## Project Overview
This project analyzes the duration of Netflix Movies and TV Shows using Python, Pandas, and Matplotlib.

The goal is to understand movie watch time and TV Show season distribution.

## Objectives
- Analyze Movie durations in minutes.
- Calculate average Movie duration.
- Analyze TV Show season counts.
- Calculate average number of seasons.
- Visualize TV Show season distribution.

## Tools & Technologies
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Separated Movies and TV Shows.
- Extracted Movie duration in minutes.
- Extracted TV Show season counts.
- Calculated average Movie duration.
- Calculated average TV Show seasons.
- Created a season distribution visualization.

## Visualization
The project generates a bar chart showing the distribution of Netflix TV Shows by number of seasons.

## Files
- `netflix_cleaned.csv` – Cleaned Netflix dataset.
- `duration_analysis.py` – Python analysis script.
- `season_distribution.png` – TV Show season distribution chart.

## Key Insights
- Movie durations are analyzed in minutes.
- TV Shows are analyzed based on the number of seasons.
- The visualization helps understand the season distribution of Netflix TV Shows.
