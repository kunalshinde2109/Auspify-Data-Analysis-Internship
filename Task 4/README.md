# Netflix Release Year Trend Analysis

## Project Overview
This project analyzes Netflix content based on release years to understand content release trends over time.

## Objectives
- Analyze Netflix content by release year.
- Identify years with the highest content releases.
- Understand content release trends.
- Visualize yearly content distribution.

## Dataset
- Dataset: Netflix Cleaned Dataset
- Source: Netflix dataset used in previous internship tasks.
- Data contains Netflix Movies and TV Shows.

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Analysis
- Counted titles by release year.
- Sorted release years chronologically.
- Identified the year with the highest number of titles.
- Created a release year trend line chart.

## Visualization
The release year trend chart illustrates the distribution of Netflix titles across release years.

## Project Files
- `netflix_cleaned.csv` – Cleaned dataset.
- `trend_analysis.py` – Python analysis script.
- `release_year_trend.png` – Trend visualization.
- `README.md` – Project documentation.

## Conclusion
This analysis helps understand the release-year distribution of Netflix content and identify trends in the content catalog.
