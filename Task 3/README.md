# Netflix Country-Wise Content Analysis

## Project Overview
This project analyzes Netflix content distribution across different countries using Python and Pandas. It identifies the top content-producing countries and visualizes country-wise content distribution.

## Objectives
- Analyze Netflix content by country.
- Identify the top 10 countries producing Netflix content.
- Visualize country-wise content distribution.
- Generate insights from the analysis.

## Dataset
- Dataset: Netflix Cleaned Dataset
- Total Records: 8,790
- Source: Netflix Dataset (cleaned during Task 1)

## Tools & Technologies
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Handled missing country values.
- Split multi-country entries into individual countries.
- Counted content mentions by country.
- Identified the top 10 countries.

## Visualization
The project includes a dashboard showing:
- Top 10 content-producing countries.
- Top 5 countries share.
- Total country mentions.
- Number of countries represented.
- Leading content-producing country.

## Project Files
- `country_analysis.py` – Python analysis script.
- `netflix_cleaned.csv` – Cleaned dataset.
- `country_analysis_dashboard.png` – Analysis dashboard.

## Conclusion
The analysis highlights the countries with the highest Netflix content representation and provides a visual overview of global content distribution.
