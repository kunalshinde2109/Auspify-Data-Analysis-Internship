# Netflix Content Type Analysis Dashboard

## Project Overview
This project analyzes the distribution of Movies and TV Shows available on Netflix using Python. The analysis focuses on content counts and percentage distribution to understand the composition of Netflix's catalog.

## Objectives
- Analyze Movies vs TV Shows distribution.
- Calculate total content counts.
- Calculate percentage distribution.
- Visualize content distribution using charts.
- Generate insights from the analysis.

## Dataset
The project uses the cleaned Netflix dataset prepared in Task 1.

- Dataset: Netflix cleaned dataset
- Rows: 8,790
- Columns: 10

## Tools & Technologies
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Counted Movies and TV Shows.
- Calculated percentage distribution.
- Created a bar chart for content count comparison.
- Created a pie chart for content percentage distribution.
- Identified key insights.

## Results

| Content Type | Count | Percentage |
|---|---:|---:|
| Movies | 6,126 | 69.69% |
| TV Shows | 2,664 | 30.31% |
| Total | 8,790 | 100% |

## Key Insights
- Movies represent 69.69% of the Netflix catalog.
- TV Shows represent 30.31% of the Netflix catalog.
- Movies are the majority content type in the analyzed dataset.

## Dashboard
The dashboard visualizes content counts, percentages, and key insights using bar and pie charts.
